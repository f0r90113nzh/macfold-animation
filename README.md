# MacFold Duo Animation

MacFold Duo Animation — небольшое приложение для строки меню macOS, которое связывает угол открытия крышки MacBook с анимацией складывания экрана. При закрытии крышки изображение уходит вдаль в перспективе, а на области сгиба появляется светлый эффект матового стекла.

Приложение работает локально. Снимок экрана используется только в оперативной памяти во время анимации, не сохраняется на диск и никуда не отправляется.

## Скачать

Готовые версии приложения находятся на странице [Releases](../../releases/latest).

1. Скачайте архив с `MacFold Duo Animation.app` из последнего релиза.
2. Распакуйте архив и перенесите приложение в папку **Программы** (`Applications`).
3. Запустите приложение. Его значок появится справа в строке меню macOS.
4. Если macOS не разрешает первый запуск, откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Всё равно открыть**. Также можно нажать на приложение правой кнопкой мыши, выбрать **Открыть** и подтвердить запуск.

## Разрешение на запись экрана

Разрешение требуется, чтобы приложение могло показать текущее содержимое экрана внутри анимации.

1. Нажмите значок MacFold Duo Animation в строке меню.
2. Выберите **Разрешить запись экрана…**.
3. В открывшихся системных настройках включите доступ для **MacFold Duo Animation**: **Конфиденциальность и безопасность → Запись экрана и системного аудио**.
4. Полностью завершите приложение через его меню и запустите заново.

Если macOS продолжает запрашивать разрешение, выключите доступ в системных настройках, включите его снова и перезапустите приложение.

В меню приложения можно выбрать угол, с которого начинается эффект: от 30° до 92°. Значение по умолчанию — 80°.

## Системные требования

- macOS 14 или новее;
- MacBook с доступным внутренним датчиком угла крышки;
- разрешение на запись экрана.

На некоторых моделях MacBook внутренний датчик крышки может быть недоступен. Текущее состояние датчика отображается в меню приложения.

## Сборка из исходников

Понадобится Xcode 16 или новее с установленными Command Line Tools.

```bash
git clone <URL-этого-репозитория>
cd "MacFold Duo Animation"
chmod +x build.sh
./build.sh
```

Готовое приложение появится в папке:

```text
dist/MacFold Duo Animation.app
```

Установка собранной версии:

```bash
ditto "dist/MacFold Duo Animation.app" "/Applications/MacFold Duo Animation.app"
open "/Applications/MacFold Duo Animation.app"
```

После первого запуска выдайте разрешение на запись экрана по инструкции выше.
